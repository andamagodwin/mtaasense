# Sample image attribution

All sample photos are openly licensed files from Wikimedia Commons, stored here as the 1600px-wide
renditions Commons serves (re-fetch with `uv run python seed/fetch_images.py`). They are used only as
clearly labelled **sample data** in MtaaSense demos and evaluation. Share-alike licences apply to these
files as redistributed here.

Locations used for seeded samples: Ugandan photos use approximate locations derived from their Commons
descriptions; photos taken outside Uganda are placed at *illustrative* Kampala locations and labelled as such.
